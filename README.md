# Predictive Analysis

A collection of data analysis and predictive modelling projects exploring regression techniques, time-series analysis, and data visualisation using Python and Jupyter Notebooks.

## Overview

This repository contains practical work focused on analysing data, exploring statistical relationships, developing predictive models, and communicating findings through visualisations.

The project is organised into three Jupyter Notebooks, each covering a different area of predictive analysis.

## Project Structure

| Notebook | Description |
|---|---|
| [`ca1_regression_models.ipynb`](ca1_regression_models.ipynb) | Explores regression models and predictive modelling techniques. |
| [`ca2_time_series.ipynb`](ca2_time_series.ipynb) | Focuses on time-series analysis and understanding patterns in data over time. |
| [`ca3_visualisations.ipynb`](ca3_visualisations.ipynb) | Explores data visualisation techniques for identifying patterns and communicating insights. |

## Objectives

- Explore statistical and predictive modelling techniques.
- Analyse datasets to identify patterns, relationships, and trends.
- Develop an understanding of time-dependent data.
- Use visualisations to communicate analytical findings.
- Apply Python-based tools to practical data analysis tasks.

## Technologies Used

- **Python** — data analysis and modelling
- **Jupyter Notebook** — interactive analysis and documentation
- **Regression analysis** — exploring relationships between variables
- **Time-series analysis** — analysing patterns over time
- **Data visualisation** — presenting data and analytical findings

## Getting Started

### Prerequisites

Install Python 3 and Jupyter Notebook or JupyterLab.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/roxaaaaa/Predictive-analysis.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Predictive-analysis
   ```

3. Install Jupyter Notebook if needed:

   ```bash
   pip install notebook
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open any of the three notebooks and run the cells in sequence.

**Note:** Additional Python libraries may be required depending on the imports used in each notebook. Install any missing dependencies before running the relevant analysis.
